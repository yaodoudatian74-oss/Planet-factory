# 神様の惑星工場（Planet Factory）

あなたは宇宙をみおろす神様。
名もない小さな岩の惑星をまるごと巨大工場にして、お金を稼ぎ、
惑星を **10段階** に「めちゃくちゃ」進化させる 3D ゲームです。

ブラウザだけで動きます（Three.js / WebGL）。スマホでもPCでも遊べます。

## 遊び方

| 操作 | やること |
| --- | --- |
| 惑星をタップ | お金がもらえる（神の指先） |
| ドラッグ | 惑星のまわりを回る |
| ピンチ / ホイール | ズーム |
| 「工場」タブ | 工場を建てる。工場は放っておいても毎秒お金を稼ぐ |
| 「強化」タブ | 工場やタップを2倍・3倍にパワーアップ |
| 「進化」タブ / 金色のボタン | 惑星を次の形態へ進化させる |
| 丸いボタン（神の力） | 神の雷・黄金の雨・時間加速・星降り |
| 金色の隕石 | 飛んできたらタップ。大金や「熱狂（生産×5）」がもらえる |
| 「神殿」タブ | 最終形態でビッグバン → 神格を得て新しい宇宙で再スタート |

進行は自動でブラウザに保存されます。閉じている間も工場は動き続け、戻ってくると留守中の稼ぎ（最大6時間・50%）がもらえます。

工場は12種類（採掘場 → 製鉄所 → 発電所 → … → 宇宙創造機）。進化するたびに新しい工場と神の力が解放されます。
お金の単位は 万・億・兆・京・垓・秭・穣・溝・澗・正・載・極・恒河沙・阿僧祇・那由他・不可思議・無量大数 と増えていきます。

## 起動方法

- `index.html` をブラウザで開くだけで遊べます（Three.js を CDN から読み込むのでインターネット接続が必要です）。
- GitHub Pages で公開する場合: リポジトリの Settings → Pages で、このブランチのルートを公開してください。
- ローカルサーバーで動かす場合: `npx serve .` や `python3 -m http.server` などで、このフォルダを配信してください。

## オンライン機能（協力・ミサイル）

オンラインは2通りで使えます。

- **Claude のアーティファクトのリンク**: 何も設定しなくても使えます。仲間には、アーティファクトを共有して **共同編集（Contributor）以上** で招待してください。
- **普通のブラウザ（Firebase）**: 下の手順で Firebase の設定を入れると使えます。

どちらでも、部屋の中では同じように遊べます。

1. 神殿タブの「オンライン」で部屋を作る（4文字のコードが出る）。仲間は「コードで参加」で入る。
2. 協力: 部屋にいる人が増えるほど、全員の収入が上がる（仲間1人ごとに +10%、最大 +50%）。
3. ミサイル: 部屋の中の相手に撃てる（45秒に1回）。当たった相手は、持ち金の8%（最大は毎秒収入60秒分）を失う。

注意: 攻撃の結果は受け取ったほうのブラウザで計算するため、改造すれば不正はできてしまいます。

### Firebase の設定（普通のブラウザで遊ぶとき）

オンラインは Firebase Realtime Database（無料の Spark プラン）を使います。設定を入れなければ、一人用のゲームとして遊べます。

1. https://console.firebase.google.com でプロジェクトを作る（Spark プランのまま）。
2. 「構築」→「Realtime Database」→「データベースを作成」。ルールは `rules.json` の内容を貼る。
3. 「構築」→「Authentication」→「始める」→ ログイン方法で「匿名」を有効にする。
4. 「プロジェクトの設定」→「全般」→「ウェブアプリを追加」。表示された設定の `databaseURL` などを、`js/online-config.js` の `PF_FIREBASE_CONFIG` に貼る。
5. Authentication の「設定」→「承認済みドメイン」に、ゲームを置く場所のドメイン（GitHub Pages など）を追加する。
6. ゲームをそのドメインから開くと、神殿タブの「オンライン」で部屋を作れる。部屋のコードを仲間に伝えると、仲間は「コードで参加」で入れる。

- 協力: 部屋にいる人が増えるほど、全員の収入が上がる（仲間1人ごとに +10%、最大 +50%）。
- ミサイル: 部屋の中の相手に撃てる（45秒に1回）。当たった相手は、持ち金の8%（最大は毎秒収入60秒分）を失う。

注意: 攻撃の結果は受け取ったほうのブラウザで計算するため、改造すれば不正はできてしまいます。また `rules.json` は部屋への書き込みを制限していないので、遊び用の範囲で使ってください。

## ファイル構成

```
index.html        画面のHTML
css/style.css     見た目
js/data.js        工場・形態・強化・神の力のデータ、数字の表示
js/state.js       セーブデータと経済の計算
js/audio.js       効果音（WebAudioで合成）
js/shaders.js     惑星や光のシェーダー
js/world.js       宇宙・惑星・環・月・軌道リングなどの3D
js/buildings.js   工場の3Dモデルと配置
js/fx.js          光の柱・雷・隕石・ロケットなどの演出
js/ui.js          パネルとHUD
js/main.js        操作・ゲーム進行・メインループ
js/online.js      部屋・協力・ミサイル（Claude の room / db、または Firebase）
js/online-config.js  Firebase の設定（普通のブラウザで使うとき）
rules.json        Firebase のデータベースルール
```

数値バランス（値段・収入・進化コスト）はすべて `js/data.js` にあります。普通に遊んで第10形態まで45分〜1時間ほどを目安に、シミュレーションで調整しています。
